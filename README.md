# Reiman Alfonso Azcuy — Personal Portfolio

Portafolio profesional bilingüe (ES/EN), responsive, estático y listo para GitHub Pages. Incluye seis proyectos públicos de GitHub, perfil académico y profesional, stack, experiencia y contacto.

## Cómo verlo localmente

Abre `index.html` directamente en el navegador. No requiere instalaciones ni compilación.

## Publicar en GitHub Pages

1. En GitHub crea un repositorio **público** llamado `reimanrey93.github.io` (si está disponible).
2. El sitio está integrado en un solo archivo `index.html`; no requiere CSS o JavaScript externos.
3. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)` y guarda.
4. La dirección esperada será `https://reimanrey93.github.io/` cuando GitHub Pages termine el despliegue.

También puedes usar un repositorio llamado `portfolio` y alojarlo en `https://reimanrey93.github.io/portfolio/` siguiendo las mismas opciones.

## Cambios recomendados antes de publicar

- **Contacto:** sustituir el enlace de búsqueda de LinkedIn por tu perfil real, y agregar un correo profesional si deseas hacerlo público. No se inventaron datos de contacto.
- **Fotografía:** la imagen se carga directamente desde `https://github.com/reimanrey93.png?size=600`. Si prefieres evitar dependencia externa, guarda una copia de tu foto como `profile.jpg` y cambia `src` en `index.html`.
- **Publicaciones:** agregar DOI/enlaces confirmados cuando estén listos.
- **Datos académicos:** revisar afiliación, títulos, cronología y presentación pública antes de compartir.
- **Proyectos:** cambia la selección, descripciones y enlaces desde la constante `projects` dentro de `index.html`.
- **Traducciones:** se editan en `translations` dentro de `index.html`.
